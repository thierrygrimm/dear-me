- Pax (CH) Sustainable Portfolio 75

Default example in the calculator: 80% guaranteed part, 20% fund. Return assumption for the Swiss small and mid cap fund: −0.3% (low), 6.0% (medium), 8.1% (high).

Each fund has a factsheet linked from the calculator (e.g. [Sustainable Portfolio 25](https://assets.pax.ch/x/2a412e2456/pax-fondsinformation-sustainable-portfolio-25.pdf)).
